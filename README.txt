БАРОМЕТР ПСИХОСОЦІАЛЬНОЇ БЕЗПЕКИ — ВЕРСІЯ 1.0

Структура пакета:
- index.html — публічний портал
- local/index.html — локальний робочий портал

Рекомендований спосіб передачі компаніям:
1. Опублікувати всю папку як статичний сайт (наприклад, GitHub Pages).
2. Передавати компаніям лише адресу публічного порталу.
3. Перехід до локального порталу відбувається з публічного порталу.

Важливо про локальні дані:
- Локальний портал не потребує окремого логіна.
- Дані автозберігаються у сховищі браузера для адреси локального порталу та конкретного профілю браузера.
- Сховище браузера не шифрується самим Барометром. Використовуйте захищений профіль браузера, а файли резервних копій зберігайте як чутливі дані.
- На іншому пристрої або в іншому профілі браузера автоматично збережені дані не з’являться. Для перенесення використовуйте резервну копію дослідження.
- Після завершення визначеного компанією строку зберігання видаліть дослідження кнопкою у локальному порталі.
- Для стабільного автозбереження рекомендується відкривати портал за постійною HTTPS-адресою, а не як file://.
